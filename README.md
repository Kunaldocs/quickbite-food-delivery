
# QuickBite - Food Delivery Website

## About the Project
QuickBite is a simple food delivery website developed using HTML, CSS, and JavaScript.

## Features
- Displays popular food items.
- Shows food prices.
- Allows users to add food to the shopping cart.
- Calculates the total bill.
- Displays order confirmation messages.
- Provides a responsive user interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Browse the menu and add food items to your cart.
4. View the total price and try the order button.

## Project Objective
The objective is to understand source-code management using GitHub,
including repositories, commits, branches, pull requests, and merging.
